Scooby-Doo Monster Website – Monster Corner
A Scooby-Doo-themed website featuring information about monsters and villains from the series. The website is designed as an interactive-looking reference site where visitors can explore different monsters, read their biographies, and learn about their types.

Features:
Home Page - Introduces the Monster Corner website.
Monster Profiles - Provides biographies and information about different Scooby-Doo monsters.
Monster Types - Organizes monsters by their different types.
Navigation - Allows visitors to move between the Home, Monsters, and Monster Types pages.


What I Learned
Through this project, I gained more experience with structuring multi-page websites using HTML, styling web pages with CSS, creating consistent navigation between pages, and using colour, typography, and layout to create a cohesive visual design.
